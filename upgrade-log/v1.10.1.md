# v1.10.1

::: tip 插件系统正式上线🎉

* 历经数个大版本的开发，插件系统终于在本版本正式上线啦！
* 欢迎各位感兴趣的朋友关注[插件系统设计文档](https://potatovn.net/development/client-plugin/quick-start.html)，开发你的第一个插件~
* 插件系统将会极大地扩展PotatoVN的功能（包括但不限于：更多的信息源、全新的界面、sunshine支持等），敬请期待😘。

:::

## ✨ 插件系统
* 全新的插件系统：支持插件提供自定义搜刮器、自定义设置界面、注入账户界面、注入游戏详情页、注册侧边栏按钮、跳转到插件自己的页面等
* 新增插件市场界面，可以在软件内浏览、下载、安装与卸载插件，也支持加载本地zip插件包
* 插件可以使用XAML编写UI，并支持插件数据的读取与保存
* 旧版游戏详情页从软件本体中移出，迁移至插件实现
* 开发者模式支持动态安装/热重载插件，方便插件开发调试

## ✨ 全新的游戏进程检测机制
* 全新的游戏进程检测机制，应该再也不需要手动指定游戏进程啦

## ✨ 全新的过滤面板
* 重新设计了游戏库过滤面板，过滤器状态现在可以持久化保存
* 支持设置过滤面板显示哪些子面板、一键清除所有过滤器
* 新增批量修改游玩状态等批量操作功能 [感谢@dccif的开发](https://github.com/dccif)
* 修复游戏数量较多（200+）时排序异常的问题 [感谢@KurikoMoe的修复](https://github.com/KurikoMoe)

## ✨ 游戏库升级
* 支持一个游戏同时属于多个本地库
* 支持游戏库手动排序 [感谢@KurikoMoe的开发](https://github.com/KurikoMoe)
* 大幅优化了游戏库界面的性能

## ✨ 界面自定义
* 支持自定义背景：游戏详情页背景、设置页横幅图、透明玻璃材质与背景色、图片填充模式等 [感谢@huiyuhongren的开发](https://github.com/huiyuhongren)
* 侧边栏每个按钮都可以选择是否显示了
* 新增游戏引擎字段 [感谢@Drinbol的开发](https://github.com/Drinbol)

## ✨ 搜刮器更新
* 新增[HikariNagi](https://hikarinagi.com/)搜刮器
* 支持给混合搜刮器设置各个搜刮器的超时时间
* 混合搜刮器支持按信息类型选择从哪些源获取内容
* 默认关闭混合源中的Bangumi搜刮器，避免超时影响搜刮体验（可在设置中重新打开）
* 支持关闭VNDB的Tag和谐/反剧透机制
* VNDB搜刮器支持r字头id
* 修复VNDB名称搜索排序错误 [感谢@huoshen80的修复](https://github.com/huoshen80)
* 支持从信息源手动选择游戏封面图/横幅图 [感谢@dccif的开发](https://github.com/dccif)
* 支持在游戏设置页使用剪贴板粘贴游戏封面/横幅图

## ✨ 其他更新
* 支持便携版（初步）
* 导出/导入数据时会带上各种界面设置了
* 存档自动检测新增开关，存档路径改用便携路径表示，并优化了存档检测性能 [感谢@dccif的开发](https://github.com/dccif)
* 后台任务支持取消 [感谢@Tabing010102的开发](https://github.com/Tabing010102)
